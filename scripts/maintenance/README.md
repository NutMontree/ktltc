# Database Maintenance & Data Fix Scripts

โฟลเดอร์นี้รวบรวมสคริปต์สำหรับการตรวจสอบและแก้ไข/ปรับโครงสร้างข้อมูลในฐานข้อมูล MongoDB:

- `check_subject.js`: ตรวจสอบข้อมูลรายวิชา DVE
- `check_type.js`: ตรวจสอบประเภทข้อมูลในฐานข้อมูล
- `check-digital.js`: ตรวจสอบข้อมูลสาขา/วิชาดิจิทัล
- `fix-boonchan.js`: อัปเดตและแก้ไขห้องเรียนของครูบุญจันทร์ โตมร
- `fix-phoemwithun.js`: อัปเดตและแก้ไขห้องเรียนของครูเพิ่มวิทูร
- `migrate-department.js`: สคริปต์ย้าย/แปลงชื่อแผนกวิชา
- `normalize-classrooms.js`: สคริปต์แปลงและจัดมาตรฐานชื่อห้องเรียน
- `normalize-depts.js`: สคริปต์แปลงและจัดมาตรฐานชื่อแผนก
- `test_classrooms.js`: สคริปต์ทดสอบดึงข้อมูลห้องเรียน
- `test_update.js`: สคริปต์ทดสอบการอัปเดตข้อมูล
- `update-rooms-2.js`: สคริปต์อัปเดตข้อมูลห้องเรียนชุดที่ 2
- `update-unknown-rooms.js`: สคริปต์ตรวจสอบและอัปเดตห้องเรียนที่ไม่ทราบชื่อ
